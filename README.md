# Developer Profile Page - Week 01 Project

A responsive personal developer portfolio page built using semantic HTML5 and modern CSS3, featuring project listings and a fully functional contact form integrated with Web3Forms.

## Tech Stack
* **Frontend:** HTML5, CSS3
* **Form Handling:** Web3Forms API
* **Hosting & Deployment:** GitHub & Vercel
